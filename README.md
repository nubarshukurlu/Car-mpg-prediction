# Car MPG Prediction

## Project Summary

This project explores how different vehicle features affect fuel efficiency (MPG).  
Using machine learning and polynomial regression, the model predicts MPG values based on car characteristics.

The project also investigates nonlinear relationships between variables to improve prediction performance.

---

## Tools and Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

---

## What Was Done

- Cleaned and prepared the dataset
- Explored data patterns and correlations
- Applied feature engineering techniques
- Built regression and polynomial regression models
- Compared model performance and evaluation metrics
